## 1. 论文基本信息
- **Title**: Perception into Imagination: Executable Memory for World Models
- **Journal**: arXiv preprint
- **First Author**: Li
- **领域定位**: 世界模型中的显式感知记忆与规划

## 2. 研究背景与痛点
视觉/触觉智能体在物体或地标离开当前感知后仍需使用历史感知信息；包括 Memory Maze、MiniWorld 和触觉相关设置。 主要为受控模拟和有限触觉演示；交互预算、任务规模与记忆状态设计影响结果，向真实复杂机器人环境迁移仍需验证。 本文聚焦的问题是：历史感知内容在视线/接触消失后，如何随行动更新并影响未来决策？

## 3. 核心材料与方法
Executable Perceptual Memory (EPM)在神经潜在动力学之外显式推进感知状态，并将其读出用于奖励预测、价值估计和策略学习。奖励输入与产生奖励的状态转移对齐，并在记录动作的开放环滚动上监督奖励头。

比较完整EPM与同一逐步读出仅供策略/价值使用的感知前端；通过视觉实现、记忆探针、触觉恢复和真实触觉帧分析记忆的不同作用。 Memory Maze 13×13；在1M交互时报告平均回报30.37，对照设置23.37；另评估9×9及MiniWorld。

## 4. 关键发现与机制解析
### 1. 在Memory Maze 13×13、1M交互设置下，完整EPM回报为30.37，对照为23.37，差值7.00，论文给出区间[3.80,10.21]。

### 2. 显式记忆不仅保存内容，还随动作推进相对状态，使奖励预测能利用不可见目标/接触的变化后果。

### 3. 在9×9和MiniWorld控制任务也报告改善；浓度、触觉恢复与真实触觉帧实验显示不同记忆用途。

## 5. 局限性与未来展望
主要为受控模拟和有限触觉演示；交互预算、任务规模与记忆状态设计影响结果，向真实复杂机器人环境迁移仍需验证。 如何在真实机器人中扩展记忆表示，控制长期漂移，并验证奖励预测与实体世界后果一致？

## 6. 核心思考与研究启发
可借鉴将观测历史转化为可更新、可查询的显式状态，并让该状态参与下游预测，而不只作为静态上下文。 EPM把显式感知状态与潜在动力学共同推进，并将记忆读出用于奖励、价值和策略学习。在Memory Maze等受控任务中的结果支持：记忆机制的价值不仅在于保存历史观测，还在于追踪其随动作变化的决策含义。

**方法论延伸：**具身记忆；世界模型；部分可观测控制；奖励建模；机器人触觉。可进一步检验不同任务分布、数据规模和计算预算下的稳定性，并保留从结论回溯到原始证据的路径。
